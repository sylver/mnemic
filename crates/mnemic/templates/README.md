# mnemic vault

This repository is a [mnemic](https://github.com/sylver/mnemic) vault: plain Markdown notes with YAML frontmatter. `mnemic.toml` marks the vault root.

The vault is managed through the `mnemic` command-line tool, not edited by hand. `mnemic --help` lists the commands.

Agents: run `mnemic skill` for the agent guide before you read or write notes.

The CLI does not commit or push. Commit and push changes with Git.

Tool, docs, and releases: https://github.com/sylver/mnemic
