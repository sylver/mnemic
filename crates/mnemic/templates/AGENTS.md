# Vault agents

Read this file before editing a note.

1. Create notes with `mnemic new <type>`, which applies the type template. Read this file before editing a note.
2. Search the vault before creating a page. Update an existing entity instead of adding a duplicate.
3. One file per entity. File it in the folder the type pack names, or leave it in `inbox/` and say so.
4. Rewrite compiled truth when the current state changes. Append to the timeline. Do not rewrite old timeline lines.
5. Never edit files under `sources/raw/`.
6. Prefer the `mnemic` CLI with `--json` over hand-rolled YAML when a verb exists.
7. The CLI does not commit or push. You own the Git commit.
8. A human correction is written immediately, not batched.
