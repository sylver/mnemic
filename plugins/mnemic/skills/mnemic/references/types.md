# Core types

Generated from the embedded pack `TypeDef` and `FieldDef` values. Do not edit this file by hand. Run `cargo run -p mnemic-core --bin mnemic-contract`.

`folder` in TOML is `folders` here. A string becomes one entry. A list stays a list. `type` in TOML is `kind`: `string`, `strings`, or `date`. `target` is set when the field points at another type.

A file `<vault>/types/<type>.toml` replaces that type declaration whole. `<vault>/types/<type>.md` replaces that type's body template. The same file stem wins over the built-in type.
